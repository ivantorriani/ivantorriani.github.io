Refining my Idea

December 16, 2025

Clarifying my Focus

Before, I was planning on having the briefing take place over multiple different podcasts. I assumed that there would need to be individual pages for breaking updates, deep dives, past/future developments, etc... but I'm realizing a couple problems with it. One, it's such a massive time commitment to sit and listen to multiple different podcasts, that it might just cause people to get tired and switch away. Second, quality podcasts should cover all the needed information. So now I"m going to focus on one main podcast, the 'analyst' feature, and the design of the homepage.

Coming to Terms with the Technology

Obviously we are using nextjs for the website itself. I set up the github repo (the right way this time, finally). I'm going to use Ollama for the analyst feature-- at the moment it's just going to be an average chatbot, but in the future, I would love if I replaced it with a voice model that supported live interuptions, but let's start simple. In the future, I also want it to recieve information from the podcast, but again, future. I am aware of Spotify's API to immediately get the latest episode of a certain show, so this should't be that challenging either. I want to spend some time working on a design -- I like the idea of using very modern sleek design with artworks that represent democracy / etc...

So tomorrow, I will start implementing some of the features onto the website. I will start designing the homepage and working on a couple ideas. I have to remember that the first draft is always not going to be perfect and that any quality product is going to need multiple iterations.
