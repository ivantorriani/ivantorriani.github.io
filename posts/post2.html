Today I learned a lot, from implementing the network, to loading data, and a training loop

We initialize a network with custom class with num_inputs and num_outputs corresponding to the size of each of our batches, and a desired representation of the data. I then learned how to create layers, mainly linear layers represented by \( z = w_1 x_1 + b \) with \( w_1 \in \mathbb{R}^{n} \), where \( n \) can be adjusted based on our desired —right now it’s a bit arbitrary. We also have a forward function to pass through our network once, and be able to calculate loss and so forth.

Dataset loaders are kinda self explanatory. We’re going to create a custom class Dataset(Dataset) class with the torch functionalities, and create functionality in order to get features and labels (as in the input and the expected output). Then we’re going to use a data loader that will be used when we train the model to pass our data in, with helpful functionalities like batch_size and num_workers .

Finally, I learned about a basic training loop. After calling our custom model class, setting up the optimizer with the learning rate, and setting the amount of epochs, we begin. We iterate for the value stored in epochs times, each time taking a full forward pass through the model, iterating through our data batch, and calculating loss

For the most interesting part, after we have calculated the loss of every feature and label, we need to improve the model, right? This is where backpropogation happens, or the calculation of gradients:

$$ \frac{\partial loss}{\partial w_1} \wedge \frac{\partial loss}{\partial b} $$

While this is not totally understood, I know that it is able to optimize the parameters for the next pass. Super interesting. Finally, I learned about some functions that I just copy pasted in order to compute the accuracy of the model after training, and loading the model.
